## 一、技术选型与版本说明

### 为什么选择 Motion？

Motion（原 Framer Motion）是 React 生态的**标准动画库**，被数千个生产级应用使用。与你的技术栈完美契合：

| 维度                | 兼容性                                     |
| ------------------- | ------------------------------------------ |
| **React 19**        | ✅ 官方支持（motion 或 framer-motion@12.x） |
| **Tailwind CSS v4** | ✅ 已验证                                   |
| **Tauri 2**         | ✅ 无冲突                                   |
| **shadcn/ui**       | ✅ 官方推荐集成方式                         |

### 安装命令

```bash
# 推荐：使用统一的 motion 包（现代入口）
pnpm add motion

# 或使用传统包名（同样支持 React 19）
pnpm add framer-motion@12.x
```

> **注意**：`motion` 包是 `framer-motion` 的现代统一入口，两者在 React 19 下均可使用。推荐使用 `motion`，导入方式为 `import { motion } from "motion/react"`。

## 二、核心动画模式（按场景分类）

### 🎯 模式一：微交互动画（按钮、卡片、图标）

**适用场景**：播放按钮、歌单卡片、控制栏图标

```tsx
import { motion } from "motion/react";
import { Play, Pause } from "lucide-react";

// 播放按钮 —— 点击缩放 + 旋转
<motion.button
  whileTap={{ scale: 0.85 }}
  whileHover={{ scale: 1.05 }}
  transition={{ type: "spring", stiffness: 400, damping: 17 }}
  onClick={togglePlay}
  className="rounded-full bg-primary p-4 text-white"
>
  {isPlaying ? <Pause /> : <Play />}
</motion.button>

// 歌单卡片 —— 悬停上浮 + 阴影加深
<motion.div
  whileHover={{ y: -6, boxShadow: "0 20px 40px rgba(0,0,0,0.3)" }}
  transition={{ type: "spring", stiffness: 300, damping: 20 }}
  className="glass rounded-xl p-4"
>
  <img src={cover} className="aspect-square w-full rounded-lg" />
  <h4 className="mt-2 font-medium">{title}</h4>
</motion.div>
```

**设计要点**：
- 使用 `type: "spring"` 产生物理回弹感，比线性动画更自然
- `stiffness` 控制弹性速度，`damping` 控制回弹幅度
- 避免与 Tailwind 的 `transition-*` 类混用，以免卡顿

### 🎯 模式二：列表交错出现动画（歌单、搜索结果、推荐列表）

**适用场景**：首页推荐列表、搜索结果、专辑曲目列表

```tsx
import { motion } from "motion/react";

// 容器 variants —— 控制子元素交错
const containerVariants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.06, // 每个子项延迟 0.06 秒
      delayChildren: 0.1,
    },
  },
};

// 子项 variants —— 从右侧滑入 + 淡入
const itemVariants = {
  hidden: { opacity: 0, x: 30 },
  visible: {
    opacity: 1,
    x: 0,
    transition: { type: "spring", stiffness: 300, damping: 24 },
  },
};

// 使用
<motion.div
  variants={containerVariants}
  initial="hidden"
  animate="visible"
  className="grid grid-cols-5 gap-4"
>
  {tracks.map((track) => (
    <motion.div key={track.id} variants={itemVariants}>
      <TrackCard track={track} />
    </motion.div>
  ))}
</motion.div>
```

**设计要点**：
- `staggerChildren: 0.06` 让列表项依次出现，形成“瀑布流”效果
- 交错动画让列表看起来更精致，代码量极少
- 如果列表超过 50 项，考虑配合虚拟滚动（如 `react-window`）

### 🎯 模式三：页面切换转场动画

**适用场景**：路由切换（首页 → 专辑页 → 歌词页等）

```tsx
import { motion, AnimatePresence } from "motion/react";
import { useLocation, Outlet } from "react-router-dom";

// 页面转场组件 —— 包裹路由出口
function PageTransition() {
  const location = useLocation();

  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={location.pathname}
        initial={{ opacity: 0, y: 12 }}
        animate={{ opacity: 1, y: 0 }}
        exit={{ opacity: 0, y: -8 }}
        transition={{ duration: 0.25, ease: "easeInOut" }}
        className="h-full"
      >
        <Outlet />
      </motion.div>
    </AnimatePresence>
  );
}

// 在 App.tsx 中使用
<Routes>
  <Route element={<PageTransition />}>
    <Route path="/" element={<Home />} />
    <Route path="/album/:id" element={<AlbumPage />} />
    <Route path="/artist/:id" element={<ArtistPage />} />
    <Route path="/lyrics" element={<LyricsPage />} />
    {/* 其他路由 */}
  </Route>
</Routes>
```

**设计要点**：
- `mode="wait"` 确保旧页面退场动画完成后，新页面才进场
- 使用 `key={location.pathname}` 让 AnimatePresence 识别路由变化
- 淡入淡出 + 轻微位移是最稳妥的转场方式，不会让用户眩晕

### 🎯 模式四：歌词同步滚动与高亮（核心功能）

**适用场景**：歌词页（`/lyrics`），当前行随播放进度自动居中高亮

```tsx
import { motion, AnimatePresence } from "motion/react";
import { useRef, useEffect, useState } from "react";
import { usePlayerStore } from "@/stores/playerStore";

function LyricsPage() {
  const { currentTrack, currentTime } = usePlayerStore();
  const [lyrics, setLyrics] = useState<LyricsLine[]>([]);
  const containerRef = useRef<HTMLDivElement>(null);
  const [isUserScrolling, setIsUserScrolling] = useState(false);
  const timeoutRef = useRef<NodeJS.Timeout>();

  // 计算当前行索引
  const activeIndex = lyrics.findIndex(
    (line, i) =>
      line.time <= currentTime &&
      (i === lyrics.length - 1 || lyrics[i + 1].time > currentTime)
  );

  // 自动滚动到当前行
  useEffect(() => {
    if (isUserScrolling || activeIndex < 0) return;
    const target = containerRef.current?.children[activeIndex] as HTMLElement;
    target?.scrollIntoView({ block: "center", behavior: "smooth" });
  }, [activeIndex, isUserScrolling]);

  // 用户滚动后 2 秒恢复自动跟踪
  const handleScroll = () => {
    setIsUserScrolling(true);
    clearTimeout(timeoutRef.current);
    timeoutRef.current = setTimeout(() => setIsUserScrolling(false), 2000);
  };

  return (
    <div
      ref={containerRef}
      onScroll={handleScroll}
      className="h-full overflow-y-auto py-16 scroll-smooth"
    >
      <div className="mx-auto max-w-lg space-y-2 text-center">
        {lyrics.map((line, i) => (
          <motion.p
            key={i}
            animate={{
              color: i === activeIndex ? "#007AFF" : "rgba(255,255,255,0.5)",
              scale: i === activeIndex ? 1.08 : 1,
              fontWeight: i === activeIndex ? 600 : 400,
            }}
            transition={{ duration: 0.15, ease: "easeOut" }}
            className="text-lg"
          >
            {line.text}
          </motion.p>
        ))}
      </div>
    </div>
  );
}
```

**设计要点**：
- 使用 `scale` 而非 `fontSize` 实现高亮放大，避免重排
- 动画持续时间 `0.15s` 足够快，能跟上音乐节奏
- 用户滚动后暂停自动跟踪 2 秒，尊重用户操作意图

### 🎯 模式五：shadcn/ui 组件动画化

**适用场景**：让 shadcn 组件具备动画能力

使用 `motion.create()` 将任意 shadcn/ui 组件包装为可动画组件：

```tsx
import { motion } from "motion/react";
import { Card } from "@/components/ui/card";
import { Button } from "@/components/ui/button";

// 创建动画版 Card
const AnimatedCard = motion.create(Card);

// 创建动画版 Button
const AnimatedButton = motion.create(Button);

// 使用
<AnimatedCard
  whileHover={{ y: -4 }}
  transition={{ type: "spring", stiffness: 300 }}
  className="glass"
>
  <AnimatedButton
    whileTap={{ scale: 0.95 }}
    onClick={handlePlay}
    variant="default"
  >
    播放
  </AnimatedButton>
</AnimatedCard>
```

**设计要点**：
- `motion.create()` 保留了 shadcn 组件的所有 props 和样式
- 可以动画化任何 React 组件，不限于 shadcn

## 三、性能优化最佳实践

### 1. 使用 LazyMotion 按需加载

Motion 完整包约 34 KB，使用 `LazyMotion` 可将体积降至 **4.6 KB**：

```tsx
import { LazyMotion, domAnimation, m } from "motion/react";

// m 是 motion 的轻量版本
function App() {
  return (
    <LazyMotion features={domAnimation}>
      <m.div animate={{ opacity: 1 }}>
        {/* 你的应用 */}
      </m.div>
    </LazyMotion>
  );
}
```

### 2. 尊重用户的“减少动效”偏好

```tsx
import { MotionConfig } from "motion/react";

// 在 App 根组件包裹
<MotionConfig reducedMotion="user">
  {/* 你的应用 */}
</MotionConfig>
```

当用户系统开启了“减少动效”，Motion 会自动降级动画。

### 3. 避免动画大量列表项（> 50）

对于超长列表，优先使用虚拟滚动（`react-window` + `@tanstack/react-virtual`），再对可见项应用动画。
